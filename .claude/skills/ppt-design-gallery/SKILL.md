# PPT 디자인 갤러리 (20종)

슬라이드를 만들 때 **디자인 이름만 부르면** 해당 스타일이 적용되도록, 20종의 디자인 토큰을 한곳에 모은 갤러리입니다. 실제 `.pptx` 빌드는 `/mnt/skills/public/pptx/SKILL.md`(pptx 스킬)로, 제작 프로세스는 `claude-code-ppt` 스킬로 진행하고, 이 문서로 **색·폰트·레이아웃 토큰을 고정**합니다.

## 쓰는 법 (가장 쉬운 선택 방법)

슬라이드 제작을 요청할 때 문장 앞에 **디자인 이름(또는 번호)** 을 붙이면 됩니다.

```
"Noir 스타일로 브랜드 소개 5장 만들어줘"
"9번 디자인으로 이 보고서를 슬라이드로"
"글래스모피즘(다크)으로 제품 피치덱"
"다음 파트도 같은 디자인으로"   ← 토큰 그대로 유지
```

- 이름을 안 대면 → 기본 `pptx-master`(Claude Brand)로.
- 한 덱을 여러 파트로 나눌 때는 **처음 고른 디자인 토큰을 끝까지 유지**한다.

## 선택 표 (번호 · 부르는 법 · 무드)

## 공통 규칙

- 비율 16:9, 가장자리 여백 최소 64px, 슬라이드당 메시지 1개·불릿 4~5개 이하.
- 텍스트는 개조식·명사형 종결. 강조는 핵심 1~2개에만.
- pptxgenjs는 **그라디언트·블러·소프트 섀도우를 네이티브 미지원** → 타이틀/디바이더 등 꼭 필요한 곳은 **이미지 슬롯**으로 넣거나 단색 포인트로 대체(프로세스는 `claude-code-ppt` 참조). hex는 `#` 없이 표기.

# 디자인 토큰 (15종)

> ★ 5종(01~05)은 전용 스킬(`pptx-master-skills`·`lecture-slide-creator-v3`·`ppt-design-1`·`lecture-slide-creator`·`slive-ppt`)의 토큰을 그대로 따른다.

### 06. Editorial — 매거진 세리프
- 배경 `F7F4EE`(웜페이퍼) / 다크면 `1A1714` / 포인트 레드 `C0392B` / 본문 `3C372F` / 뮤트 `8C8578` / 룰 `D8D2C6`
- 폰트: 제목 Noto Serif KR 600–700, 라벨·본문 Pretendard
- 시그니처: 초대형 드롭 글자, 다단 본문, 풀블리드 풀쿼트, 상단 트래킹 키커
- 용도: 에세이·브랜드북·기고·문화

### 07. Gridwork — 스위스 그리드
- 배경 `FFFFFF` / 잉크 `111111` / 시그널 레드 `E4002B` / 뮤트 `767676`
- 폰트: Pretendard 900(올캡스 제목) + JetBrains Mono(넘버)
- 시그니처: 두꺼운 상단 룰(6px), 격자 카드, 데이터 바, 레드 블록 1개
- 용도: 테크·컨설팅·시스템 리포트

### 08. Aurora — 파스텔 글래스(라이트)
- 배경: 파스텔 메시 그라디언트 `#EFE9FF→#E4F3FF` + 블롭(라벤더·핑크·민트·피치)
- 글래스: `rgba(255,255,255,0.55)` + blur(24px) + 흰 테두리; 텍스트 `2A2440` / 뮤트 `6B6485` / 바이올렛 `7C6BF5`
- 시그니처: 프로스티드 글래스 카드, 라운드 26px, 은은한 그림자
- 용도: SaaS·프로덕트·앱

### 09. Noir — 다크 럭셔리 골드
- 배경 `0C0C0E`(엘리베이티드 `16151A`) / 골드 `C8A45C` / 크림 `EDE7DA` / 뮤트 `8A8578` / 라인 `2A2822`
- 폰트: Noto Serif KR 400(제목), Pretendard 400 트래킹(라벨)
- 시그니처: 얇은 골드 헤어라인, 중앙 정렬, 넓은 여백, 모노그램
- 용도: 명품·주얼리·프리미엄·파이낸스

### 10. Terminal — 사이버펑크 네온
- 배경 `05070A` + 미세 그리드(라인 `152018`) / 그린 `39FF6A` / 시안 `22D3EE` / 마젠타 `FF2E88` / 텍스트 `C8FFD4` / 뮤트 `5A7A66`
- 폰트: JetBrains Mono 전면
- 시그니처: 프롬프트(`>`)·`//` 주석, 네온 글로우, 모듈 리스트, ASCII 바
- 용도: 개발·보안·데이터 인프라·해커톤

### 11. Bloom — 웜 파스텔 소프트
- 배경 `FBF6EF` / 피치 `F7C9A8` · 세이지 `B9CBA3` · 블러시 `F4B8C1` · 스카이 `A9CBE0` / 잉크 `4A3F35` / 뮤트 `8C8073`
- 폰트: Pretendard
- 시그니처: 큰 라운드(36px+), 오가닉 원형, 알약형 스탯
- 용도: 웰니스·헬스케어·교육·리테일

### 12. Press — 뉴스페이퍼
- 배경 `F4F1E9`(뉴스프린트) / 잉크 `1A1A1A` / 레드 `B22222` / 뮤트 `5C5750`
- 폰트: Noto Serif KR(헤드라인) + Pretendard(본문)
- 시그니처: 이중 괘선 마스트헤드, 데이트라인, 다단, 드롭캡, "이어보기" 인덱스
- 용도: 리포트·아카이브·에디토리얼 기획

### 13. Atlas — 미드센추리 모던
- 배경 `EFE7D3`(크림) / 머스타드 `E0A526` · 틸 `2E7D6F` · 러스트 `C1502E` / 잉크 `2B2622` / 크림텍스트 `F7F1E3`
- 폰트: Pretendard 800
- 시그니처: 원·반원·부채꼴 기하 구성, 비대칭 컬러 블록
- 용도: 레트로·문화·헤리티지·아카이브

### 14. Blueprint — 설계도
- 배경 `0E3A5F` + 그리드(라인 `2C6A9E`) / 시안 `7FE3FF` / 화이트 `EAF4FF` / 뮤트 `8FB8D6`
- 폰트: JetBrains Mono(주석) + Pretendard(제목)
- 시그니처: 도면 프레임, 치수선·⌀표기, `//` 주석, 타이틀블록
- 용도: 엔지니어링·건축·제품 설계·기술 문서

### 15. Hanji — 한국 전통 단청
- 배경 `EDE3CE`(한지, 다크면 `241E17`) / 잉크 `241E17` / 단청 적 `B23A34`·청 `2A5C8A`·녹 `3E7A55` / 골드 `C79A3E` / 뮤트 `7A6F5C`
- 폰트: Noto Serif KR(먹), Pretendard(라벨)
- 시그니처: 세로 컬러 밴드, 한자 병기(傳統), 상단 카드 컬러 룰
- 용도: 전통문화·공예·국악·헤리티지 브랜드

### 16. Datablock — 데이터 대시보드
- 배경 `F4F6FA` / 카드 `FFFFFF`(보더 `E2E8F0`) / 블루 `2563EB` · 틸 `0EA5A4` · 앰버 `F59E0B` · 레드 `EF4444` / 잉크 `0F172A` / 뮤트 `64748B`
- 폰트: Pretendard
- 시그니처: 타일 카드, 바/도넛(conic-gradient)/프로그레스, KPI 델타
- 용도: 분석 리포트·KPI·운영 보고

### 17. Botanical — 세이지 오가닉
- 배경 `EEF1E6`(패널 `F6F8EF`, 다크면 `5F7350`) / 그린 `5F7350` · 세이지 `8A9B78` / 골드 `B79A57` / 잉크 `2E3627` / 뮤트 `7C8570`
- 폰트: Noto Serif KR(제목), Pretendard(본문)
- 시그니처: 잎사귀 라인 모티프(`border-radius:0 100% 0 100%`), 골드 디테일
- 용도: 스파·웰니스·오가닉·라이프스타일

### 18. Neumorph — 뉴모피즘(소프트 UI)
- 배경 `E4E9F1`(모든 요소 동일 배경색) / 텍스트 `3A4256` / 뮤트 `8A93A6` / 액센트 `5B7CFA`·`7C4DFF`
- 그림자: 돌출 `-9px -9px 18px #FFFFFF, 9px 9px 20px #B4BECF` / 함몰 `inset ...`
- 시그니처: 단색 위 이중 그림자, 큰 라운드, 인셋 아이콘 원
- 용도: 앱 UI·대시보드·핀테크 소프트 톤

### 19. Glassmorph — 다크 글래스모피즘
- 배경 `0B0E1C`(딥 네이비) + 블러 블롭(퍼플 `7C3AED`·시안 `0891B2`·핑크 `DB2777`, blur 90px)
- 글래스: `linear-gradient(145deg, rgba(255,255,255,.12), rgba(255,255,255,.05))` + blur(26px) + 테두리 `rgba(255,255,255,.22)` + 상단 하이라이트
- 텍스트: 제목 `FFFFFF` / 본문 `rgba(255,255,255,.82)` / 라벨 `rgba(255,255,255,.55)` — 다크 위 고대비 가독성
- 시그니처: 어두운 캔버스 위 또렷한 유리 패널, 발광 블롭
- 용도: 프로덕트·테크·이벤트(다크 모드)

### 20. Claymorph — 클레이 3D 점토
- 배경 `EDE2FB`(라벤더) / 퍼플 `A78BFA` · 핑크 `F79FD0` · 민트 `66E0B0` · 피치 `FDBA74` · 스카이 `7DD3FC` / 텍스트 `4B3B6E` / 뮤트 `8E7FB0`
- 클레이 그림자: `14px 18px 40px rgba(150,120,200,.35), inset 7px 7px 14px rgba(255,255,255,.75), inset -8px -8px 16px rgba(120,90,170,.20)`
- 시그니처: 통통하게 부푼 3D 원형·카드, 아주 큰 라운드(40px+), 캔디 파스텔
- 용도: 키즈·앱 온보딩·이벤트·굿즈
