# 슬라이브 (Slive) — Dark Keynote / Electric Gradient

**다크 캔버스 위 일렉트릭 그라디언트**로 강렬한 인상을 주는 테크 발표·스타트업 피치·제품 키노트용 PPT 디자인 시스템입니다. 이 저장소의 다른 PPT 스킬이 모두 밝은 톤(크림·화이트)인 것과 달리, 슬라이브는 **다크 모드**를 기본으로 하여 한눈에 구분됩니다.

실제 PPTX 파일을 만들 때는 이 스킬로 디자인 토큰을 고정하고, `/mnt/skills/public/pptx/SKILL.md`(pptx 스킬)의 pptxgenjs 빌드 절차를 따르세요.

## 언제 이 스킬을 쓰는가

- "슬라이브" / "Slive" 스타일, "다크 키노트", "그라디언트 슬라이드"로 만들어 달라는 요청
- 스타트업 피치덱, 제품 런칭, 테크 컨퍼런스 발표 등 **강렬하고 모던한 다크 톤**이 어울리는 자리
- 이미 슬라이브로 만든 덱의 "Part 2", "다음 파트"를 제작할 때 → **아래 디자인 토큰을 절대 바꾸지 말고 그대로 재사용**

밝고 절제된 톤이 필요하면 이 스킬 대신 `pptx-master-skills`(크림·코랄), `lecture-slide-creator-v3`(모노크롬 미니멀), `ppt-design-1`(순백 플랫)을 사용한다.

## 디자인 토큰 (고정값 — 파트 간 절대 변경 금지)

### 컬러 팔레트
| 역할 | 값 | 용도 |
|---|---|---|
| 배경 (Canvas) | `#0A0E1A` | 딥 네이비-차콜, 모든 슬라이드 기본 배경 |
| 배경 대체 (Elevated) | `#131A2E` | 카드·박스 등 한 단계 밝은 면 |
| 포인트 1 (Electric Blue) | `#4F8BFF` | 주 강조·링크·핵심 키워드 |
| 포인트 2 (Violet) | `#A855F7` | 보조 강조·그라디언트 중간 |
| 포인트 3 (Magenta) | `#EC4899` | 그라디언트 끝·경고/하이라이트 극점 |
| 그라디언트 | `#4F8BFF → #A855F7 → #EC4899` | 섹션 디바이더·대형 넘버·타이틀 강조 (좌상 45°) |
| 텍스트 (Primary) | `#FFFFFF` | 제목·핵심 본문 |
| 텍스트 (Muted) | `#94A3B8` | 부제·캡션·보조 설명 |
| 구분선/보더 | `#243049` | 얇은 라인, 1px |

### 타이포그래피
| 요소 | 스타일 |
|---|---|
| 대제목 (Display) | Pretendard **ExtraBold(800)**, 44–60pt, 흰색 또는 그라디언트 |
| 제목 (Title) | Pretendard **Bold(700)**, 28–36pt, 슬라이드당 1개 |
| 본문 (Body) | Pretendard Regular(400), 16–20pt, 불릿 형태 |
| 라벨/넘버 (Mono) | JetBrains Mono / Roboto Mono, 대문자 자간 넓게, `01` · `KPI` 등 |
| 권장 폰트 | Pretendard(국·영문 통일), 없으면 Noto Sans KR / 시스템 산세리프 |

- 국·영문 혼용 시 한 패밀리로 통일한다.
- 넘버·섹션 인덱스·유닛(%, x, +)은 Mono로 처리해 테크 무드를 강화한다.

### 레이아웃 원칙
| 항목 | 값 |
|---|---|
| 슬라이드 비율 | 16:9 (기본) |
| 가장자리 여백 | 최소 64px |
| 슬라이드당 불릿 | 최대 4개 (밀도 낮게, 화이트스페이스 확보) |
| 좌측 액센트 바 | 콘텐츠 슬라이드 제목 왼쪽에 4px 그라디언트 세로바 |
| 텍스트 종결 | 개조식·명사형, 짧고 단정하게 |
| 강조 | 핵심 단어 1–2개만 포인트 컬러 또는 그라디언트로 |

## 표준 레이아웃 7종

1. **타이틀** — 다크 배경, 초대형 그라디언트 대제목 + Mono 부제(날짜·연사) + 하단 얇은 그라디언트 라인
2. **섹션 디바이더** — 풀블리드 그라디언트(또는 다크+대형 Mono 넘버 `01`), 섹션명 흰색 볼드
3. **아젠다/오버뷰** — 좌측 세로 넘버 리스트(Mono 01–04) + 우측 항목명, 현재 항목만 포인트 컬러
4. **콘텐츠** — 좌측 4px 그라디언트 바 + 제목, 아래 최대 4불릿(각 불릿 앞 포인트색 도트)
5. **대형 KPI/스탯** — 초대형 그라디언트 넘버(72–120pt) + 한 줄 설명, 필요 시 2–3개 가로 배치
6. **비교 (2-Column)** — 좌/우 Elevated 카드, 한쪽만 포인트 보더로 강조(권장안)
7. **클로징** — 다크 배경, 그라디언트 로고/키워드 + 연락처 Mono, 여백 넉넉히

## pptxgenjs 빌드 스니펫

pptx 스킬로 빌드할 때 아래 토큰을 그대로 쓴다.

```js
// ── Slive 디자인 토큰 ──
const SLIVE = {
  bg:      "0A0E1A",
  card:    "131A2E",
  blue:    "4F8BFF",
  violet:  "A855F7",
  magenta: "EC4899",
  white:   "FFFFFF",
  muted:   "94A3B8",
  border:  "243049",
  fontHead: "Pretendard",
  fontMono: "JetBrains Mono",
};

// 모든 슬라이드 기본 배경
slide.background = { color: SLIVE.bg };

// 그라디언트는 pptxgenjs 네이티브 미지원 → 3색 중 문맥에 맞는 단색 강조로 대체하거나,
// 타이틀/디바이더는 blue→violet→magenta 3색 텍스트 그라디언트 이미지를 슬롯으로 삽입.

// 좌측 액센트 바 (콘텐츠 슬라이드)
slide.addShape("rect", { x: 0.5, y: 1.0, w: 0.06, h: 0.8, fill: { color: SLIVE.blue } });

// 대형 KPI 넘버
slide.addText("92%", { x: 0.5, y: 1.5, fontSize: 96, bold: true, color: SLIVE.blue, fontFace: SLIVE.fontHead });

// Mono 섹션 넘버
slide.addText("01", { x: 0.5, y: 0.5, fontSize: 24, color: SLIVE.magenta, fontFace: SLIVE.fontMono, charSpacing: 4 });
```

> 그라디언트가 꼭 필요한 타이틀·디바이더 슬라이드는 pptxgenjs가 텍스트 그라디언트를 지원하지 않으므로, 그라디언트 배경·타이포는 **이미지 슬롯**으로 처리하거나 단색 포인트로 대체한다(제작 프로세스는 `claude-code-ppt` 스킬 참조).

## 체크리스트

- [ ] 모든 슬라이드 배경이 `#0A0E1A` 다크 캔버스인가
- [ ] 포인트 컬러는 blue/violet/magenta 3종만 썼는가 (그 외 색 금지)
- [ ] 슬라이드당 불릿 4개 이하, 여백 충분한가
- [ ] 넘버·라벨·유닛에 Mono 폰트를 적용했는가
- [ ] 제목은 슬라이드당 1개, 개조식·명사형 종결인가
- [ ] 여러 파트 제작 시 첫 파트의 토큰을 그대로 유지했는가
