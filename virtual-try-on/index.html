어떻게 동작하나요?

브라우저에서 fal.ai의 FASHN Virtual Try-On 모델을 직접 호출합니다.

1

이미지 업로드

인물 사진과 옷 이미지를 올립니다. 이미지는 브라우저 안에서 자동으로 크기 조정(최대 1024px) 후 데이터로 인코딩됩니다.

2

AI 합성 요청

fal.ai 큐(queue)에 요청을 보내고, 진행 상태를 폴링하며 기다립니다. 보통 10~40초가 걸립니다.

3

결과 확인·저장

합성된 이미지를 미리 보고 PNG/JPEG로 내려받습니다. 마음에 안 들면 옵션을 바꿔 다시 시도하세요.
