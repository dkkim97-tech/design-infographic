# 네이버 블로그 댓글 도우미 🖊️

블로그 글을 붙여넣으면 **AI가 자연스러운 댓글 초안을 만들어 주는** 웹 도구입니다.
마음에 드는 초안을 복사해서 **직접 게시**하세요.

## ✅ 무엇을 하나요

- 블로그 글 내용/주제 입력 → 버튼 클릭 → **3줄~5줄, 이모지 포함** 댓글 초안 3개 생성
- 톤 선택: 공감형 🤍 · 응원형 🎉 · 질문형 💬 · 정보 추가형 📌
- 초안별 "복사" 버튼 → 네이버 블로그에 직접 붙여넣기

## ❌ 하지 않는 것 (그리고 그 이유)

- **자동 댓글 등록 없음**
- **네이버 정책 우회 없음**

네이버 이용약관은 매크로·자동 프로그램을 통한 댓글 작성을 금지합니다. 이를 우회하는
자동 등록 기능은 계정 정지 및 법적 문제로 이어질 수 있어 **의도적으로 포함하지 않았습니다.**
이 도구는 "좋은 댓글을 쓰도록 돕는" 역할까지만 담당하고, 게시는 사람이 직접 합니다.

## 🚀 실행 방법

```bash
cd naver-comment-helper
npm install

# API 키 설정 (둘 중 하나)
export ANTHROPIC_API_KEY=sk-ant-...
# 또는 .env.example 을 참고해 환경변수를 설정

npm start
```

실행 후 브라우저에서 **http://localhost:3000** 접속.

## ⚙️ 설정 (선택)

| 환경변수 | 설명 | 기본값 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude API 키 (필수) | — |
| `COMMENT_MODEL` | 생성 모델 | `claude-opus-5` |
| `PORT` | 서버 포트 | `3000` |

> **응답 속도를 더 빠르게** 하고 싶다면 `COMMENT_MODEL=claude-haiku-4-5` 로 바꿔 보세요.
> 품질은 조금 낮아지지만 훨씬 빠르고 저렴합니다.

## 🔒 보안

- API 키는 **서버(백엔드)에만** 저장되며 브라우저로 전달되지 않습니다.
- 입력한 블로그 글은 댓글 생성에만 사용되고 서버에 저장하지 않습니다.

## 🛠 기술 스택

- Node.js + Express (백엔드 프록시)
- `@anthropic-ai/sdk` (Claude API)
- 의존성 없는 단일 HTML 프론트엔드
