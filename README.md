## AI 프롬프트 100 앱 (`app.html`)

분야별 AI 프롬프트 100선을 검색·필터·복사로 바로 쓸 수 있는 **단일 HTML 앱**입니다.
설치·빌드·인터넷 연결 없이 `app.html` 파일을 브라우저로 열기만 하면 됩니다.

**기능**
- 🔍 실시간 검색 (스킬명·해설·프롬프트 전문 통합 검색)
- 🗂️ 10개 카테고리 필터 + 난이도(기초·중급·고급) 필터
- ⭐ 즐겨찾기 (브라우저에 저장)
- 📋 프롬프트 원클릭 복사 (프롬프트만 / 해설 포함)
- 📱 모바일·데스크톱 반응형, 다크모드 자동 대응

**카테고리** — 🎓 강의 설계 · ✍️ 콘텐츠 제작 · 📊 분석 · 🎯 마케팅 실무 ·
⚙️ 업무 자동화 · 🤖 AI 에이전트 · 🔮 GEO 마케팅 · 🏛️ 공공기관 보고서 ·
🎨 AI 영상/이미지 · 🚀 AI 비즈니스 (각 10개, 총 100개)

프롬프트는 그대로 복사해 ChatGPT · Claude · Gemini 등에 붙여넣어 사용합니다.
원본 데이터: *AI 분야별 Skill 라이브러리 100* (강사 김동규 · 한콘연 AI 전임강사 · GEO마케팅연구원)
