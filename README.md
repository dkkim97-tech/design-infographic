# 클로드AI 마스터클래스 · 4주 실습 가이드

수강생용 **주차별 실습 가이드 웹앱**. 매거진 커버 히어로 + 단계별 아코디언 + 복사 가능한 프롬프트 + "준비중" 모달로 구성된, 의존성 없는 정적 사이트입니다.

## 구조

```
index.html            1주차 가이드 (똑똑한 클로드 설정 & 첫 걸음)
assets/style.css      디자인 시스템 (Claude Brand — 크림 × 코랄 × 다크네이비 × 골드)
images/
  week1-cover.svg     THE CLAUDE ISSUE 매거진 커버 (히어로)
  week2~4-cover.svg   준비중 모달 미리보기 커버
```

## 화면 구성

- **상단 주차 바** — 1주차 활성, 2~4주차는 "준비중" 모달
- **히어로 매거진 커버** — CLASSIC MAGAZINE · THE CLAUDE ISSUE
- **바로가기 툴바** — 과정 / Claude / 패들렛 / 캔바 링크
- **8단계 아코디언** — 가입 → 자기소개 → 맞춤지침 → 모델 → 스킬 → 아티팩트 → 프로젝트 → 포트폴리오
- **복사 버튼** — 강의 프롬프트를 클립보드로 바로 복사
- **필수 / 변형 / 도전** 3단 트랙, 완주 체크리스트

## 실행

빌드·의존성 없이 정적 파일만으로 동작합니다.

```bash
python3 -m http.server 8000   # → http://localhost:8000
```
