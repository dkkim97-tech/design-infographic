# style Ai — AI 가상 피팅 스튜디오

인물 사진에 모자·상의·하의·신발·액세서리를 올리면 AI가 순서대로 겹쳐 입힌
결과 이미지를 만들어 주는 단일 HTML 웹앱입니다.

- 만든사람: 김동규 강사
- 엔진: fal.ai · FASHN Virtual Try-On (브라우저에서 직접 호출)
- 단일 파일 `index.html` · 의존성/빌드 없음 (정적 배포)

## 사용
1. 페이지 우상단 **fal.ai API 키** 패널에 키 입력 (https://fal.ai/dashboard/keys)
2. 인물 사진 + 입힐 아이템 업로드
3. **합성 시작** → 결과를 다운로드·공유

키는 사용자의 브라우저에만 저장되며 서버로 전송되지 않습니다.

## 배포
정적 사이트입니다. 루트의 `index.html`이 그대로 서빙됩니다 (빌드 명령 불필요).
